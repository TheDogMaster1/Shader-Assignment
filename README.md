# Shader Assignment
This project was for the module shader programming of the Saxion University of Applied Sciences Creative Media and Game Technologies study.
This module was all about learning how to create shaders in unity and how the real time rendering pipeline works.
The project contains multiple self made shaders. A couple of those shaders mainly show images, while others change the vertices. One shader even has simplistic lighting calculations.

## instructions for this project
1. download the project and unzip it.
2. go to unity hub and press add.
3. add project from disk.
4. choose the unzipped project folder which has assets and other folders inside it.
5. open the project
6. inside unity go to Assets/Scenes and double click MainScene.
7. press play at the top
   
The game features a camera controller so you can look around. Pressing space bar during play mode will allow you to change the state of the scene.
